# 工作台不再内置 agent：写作走对话的当前模型，规则来自工作台技能（2026-10-10）

## 原则

- **需要 agent 的事交给 VibeDev 对话**：3D 导演台设计方案（多步读改场景、动作、运镜）、搭画布、做整片。
- **不需要 agent 的固定流程，一次模型调用**：帮写（生成节点的提示词）、文本节点按请求写内容、报错的 AI 解释、第三方节点（剪辑台 Pro）的 AI 剪辑建议。用的是**工作台所在对话的当前模型**（对话模型选择器显示的那个，`sessionController.projections(...).modelSelection.next`，没有就用 VibeDev Next 的默认模型）——VibeDev 账号、DeepSeek 账号、自带 Key 都行。对话里不会多出消息。
- 工作台里不再有文本模型下拉，也不再依赖账号插件的影视文本接口（`vibedevGateway`）。

## 帮写按什么规则写

原内置 agent 写一个节点的提示词时，自己先读技能 `workflow`（内嵌 SEEDANCE EPISODE DIRECTOR · PART A）、按需读 references 和模型/题材技能。现在帮写是一次调用，所以宿主按「节点类型 × 节点模型」把同样的规则**按章节标题原文摘录**（`src/write-rules.ts`；先读数据目录里用户的版本，再读包内版本），再套上一段"一次性写作"的说明：

| 节点 / 模型 | 摘录的规则 | 约字数 |
| --- | --- | --- |
| 视频 · Seedance 2.5 | PART A 底座（A0.1 剧情保真锁、A1.1 语言、A1.3 画面文字、A3.2/3.3/3.5/3.6 时长与时间轴、A5.1/5.3 站位、A6 表演、A7.4、A8.3 道具链、A11.3 保真审计、A11.4 稳定性、A12 抛光要点）+ A1.2.1 参考绑定 + **A9.2 最终格式** + A12.17.1 | 1.6 万 |
| 视频 · Seedance 2.0 | 底座 + A4.1–A4.5 资产 + **A9.1 模板** | 1.2 万 |
| 视频 · MiniMax H3 / 海螺 3 | A0.1、A1.3、A12.15（PART A 优先：不新增剧本没有的动作）+ `minimax-h3-prompt-optimizer` 的格式、硬规则、口型、自检 + 官方格式规范 | 1.4 万 |
| 视频 · 其他模型 | 底座 + A9.2.1 的时间块写法（不用英文字段外壳） | 1.1 万 |
| 图片生成 | A0.1、A1.3、A12.1–12.3 首帧与出镜 + `assets.md` 角色/场景/道具模板与验收 + 视觉设计、色彩光线的要点 | 0.9 万 |
| 音频生成 | A1.1、A12.14 声音、A12.15 台词原文 + 声音角色 | 0.2 万 |
| 文本节点 | `sourceAndScript.md` 全部 + 故事开发、剧本改编要点 | 0.5 万 |
| 题材 | 内容涉及种草/测评/口播 → `koc-video`；典当/二奢回收 → `animal-pawnshop-marketing` | — |

一次性写作的套用方式（来自对技能里 agent 流程的逐条映射）：节点已选模型 = 用户已指定，不再问 2.0 还是 2.5；一个节点 = 一段，不做全片规划和批次；时长以节点为准；只导演不编剧，超长时在节拍边界截断、不压缩台词；参考只用 `{{ref N}}`；没有参考时省略参考绑定；只输出正文。

每个配方点名的章节，测试都要求在包内技能里找得到（`tests/write-rules.spec.ts`），技能改了标题会直接失败，不会悄悄丢规则。

## 帮写带给模型的内容（`packages/nodeShared/src/useWriteBrief.ts`）

- 节点：类型、模型显示名与 id、生成模式（人话）、时长 / 比例 / 分辨率 / 声音等全部设置、用户已写的内容；
- 连线参考，按 `{{ref N}}` 真实顺序：文本给全文；图片缩成长边 768 的 JPEG，最多 6 张，模型能看图就作为图片附件，不能就写明"只按名字理解"；上游节点自己的提示词和它再上一层的输入；
- 画布名和其他节点摘要（只作背景，明确不是参考）。

写好后填回输入框（编辑器里的 `{{ref N}}` 显示成参考标签）；写的过程中用户改了输入框就不覆盖；成功提示用了哪个模型、看了几张图。

## 3D 导演台

面板里的"模型动画与运镜同步生成"（输入框、模型下拉、生成方案）去掉，换成一句提示：在 VibeDev 对话里描述动作和运镜。导演台登记节点功能：`getDirector`（返回编辑规则——原导演提示词——以及场景、方案、取景锚点、连线素材）、`startPlanDraft` → `readPlanDraft` / `editPlanDraft` → `savePlanDraft`、`discardPlanDraft`、`selectPlan`、`exportPlanVideo`。入口技能 `vibedev-film` 写了这条用法。

## 第三方节点

剪辑台 Pro 等第三方节点自带一份节点脚手架，会调 `/api/ai/models`、`/api/ai/generate`。影视模式下前者只返回一项"跟随 VibeDev 对话"，后者把一次性请求交给对话模型并按原协议回一条完整消息；带工具的多步请求直接说明"请在 VibeDev 对话里说明需求"。

## 顺带发现并修好的

| 问题 | 原因 |
| --- | --- |
| 页面上的"VibeDev 写"一直 404 | `routes/film/writePrompt.ts`（和 `fitOptions.ts`）文件存在，但从没挂进 `router.ts` |
| 帮写请求即使到了模型也是空的 | 按 OpenAI 格式发字符串消息，宿主要的是 `system` + 内容块 |
| 思考内容可能混进提示词；失败只显示"没有返回提示词" | 收下了所有带 text 的块，不看结束原因；现在只收正文增量，按结束原因报错（未登录、余额不足等） |
| 写好的提示词不显示在输入框里 | 只改了文本，没改编辑器内容 |
| 推理默认档位（通常是 high）导致很慢 | 现在按模型取最低档（off / none / minimal / low） |
| 图片节点重绘模式下帮写不知道是重绘 | `editor?.mode` 应为 `editor.value?.mode` |

去掉的：插件的 `film_write_prompt` 工具（对话里的 agent 自己就能按 `film-workflow` 写提示词，不需要再调一个模型）；桥接的 `/v1/*` 文本转发与文本模型目录。
